Parable is a gamified productivity app built around utilizing the reward systems of a 4X grand strategy game as a motivational framing device for personal productivity. 
The game is space themed where the user will expand through the stars by accomplishing real world tasks which enable gameplay rewards.
It is currently in stage 0 meaning that only the basic productivity system in place. This allows for tracking of "Quests" and their organization into "Planets".
The next stage is to begin implementing gameplay fundamentals in particular a rudimentary economy.
